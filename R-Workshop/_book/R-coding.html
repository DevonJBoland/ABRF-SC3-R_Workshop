3.1.1 Hello, world!

In all seriousness though, coding can be as simple or complex as you make it. For instance, we are going to begin by writing the first program every new coder learns in any programming langueage the Hello, world! statement. We will use the print() function from base R. We will go over each part of it shortly. Begin, typing the following in your R script:

print("Hello, world!")

As you can see the statement “Hello, world!” was output (or printed, hence the function name) below in our R console. We called the print() function which takes as input a string (text) or number as input. This print() function is used a lot across many programming langueages. You have commonly encountered it in your day-to-day jobs. When coding it is often used to print a status update, error message, warning, etc. to the user as feedback so we aren’t just starting at a static screen wondering if something has happened or we have messed up.

Now we are going to add a layer to our print() code from earlier. What if we wanted to store a message to ourselves, say remember to drink our coffee while it is still hot, and view it later. We achieve this by creating a vairable and casting (storing) a value in it using the <- operator.

3.1.2 Vector, the simplest way to store multiple data

Above we stored our first data, a single string into the variable note. But what if we wanted to store a a list of numbers? In R, a series of data is called a vector (in R we also have list objects, which behave differently but can look similar). We begin a vector using the c() and separating elements in the vector with a comma. Below, let’s create a vector of numbers 1-5.

num_vec <- c(1,2,3,4,5)
print(num_vec)

As you can see, we stored a list of the numbers 1-5 in the variable called num_vec. Unlike before, our variable now stored as numbers, specifically as integers. You’ll notice how we dropped the "" marks as we intended to store numbers instead of strings.

However we can mix data types in vectors, lets see what happends when we try to mix numbers and strings:

mix_vec <- c(1, "the", 2, "cow", 3, "moos")
print(mix_vec)
