4.3 Data Wrangling with dplyr

In this segment, we process raw billing data from iLab systems. We will clean test accounts, focus on completed/paid transactions, use the standard R native pipe |>, and parse timestamp strings into useful data features (Months and Quarter).

4.3.1 Downloading iLab Data

We are going to download our revenue reports from iLab for FY26. If you do not have access to this information in iLab, please use the data provided here.

4.3.2 Load in iLab Data

Now let’s load in our data as have done previously:

ilab_raw <- read.csv("data/module3_FY26_full.csv", header = TRUE)

4.3.3 Clean iLab Data

We have our iLab data loaded into memory and stored in the vairable ilab_raw. However, if we inspect the data we will notice it is full of n/a, or just empty data points throughout the columns of the dataframe. We need to clean up the data and get it in a state that is useful for reporting an more informative for plotting.

We are going to accomplish this using the dplyr package bundled with tidyverse. Our goals are to: * Filter out internal test accounts (Customer Name != "Test Account"), and unpaid/cancelled invoices (payment_status == "Paid"). * Parse timestamps into Month and Quarter using lubridate functions. * Format date categories cleanly for downstream visualization.

cleaned_revenue_data <- ilab_raw |>
  filter(
    Customer.Name != "Test Account",
    Billing.Status == "billing_initialized"
  ) |>
  mutate(
    date = mdy_hm(Billing.Date),
    month_num = month(date),
    month_label = month(date, label = TRUE, abbr = TRUE),
    quarter = factor(paste0("Q", quarter(date)))
  ) |>
  arrange(date)

4.4 Visualizing Revenue Trends with ggplot2

Now that our data is clean, we will aggregate revenue trends and build report-ready figures.

4.4.1 Monthly Revenue (Bar Chart)

To identify seasonal dips, we aggregate total revenue by month.

monthly_revenue <- cleaned_revenue_data |> 
  group_by(month_label) |> 
  summarise(total_revenue = sum(Total.Price), .groups = "drop")
head(monthly_revenue)
# A tibble: 6 × 2

  <ord>               <dbl>
1 Jan                37851.

4 Apr                71493.

p1 <- ggplot(monthly_revenue, aes(x = month_label, y = total_revenue)) +
  geom_col(fill = "orange", color = "white", alpha = 0.9) +
  scale_y_continuous(labels = scales::dollar_format(prefix = "$")) +
  labs(
    title="Total Monthly Revenue (FY26)",
    subtitle="Analysis of seasonal dips in core facility billing",
    x="Month",
    y="Revenue (USD)"
  ) +
    theme_minimal(base_size = 12) +
  theme(
    plot.title=element_text(face = "bold", size = 14),
    panel.grid.minor = element_blank(),
    panel.grid.major.x = element_blank()
  )

  p1

4.4.2 Quartely Revenue By Institution Type (Stacked Bar & Line Charts)

Next, we evaluate revenue per quarter broken down by Institution Type (Internal vs. External)

quarterly_institution_revenue <- cleaned_revenue_data |> 
  mutate(Institution.Type = if_else(
    Customer.Institute == "Texas A&M University",
    "Internal",
    "External"
  )) |> 
    group_by(quarter, Institution.Type) |> 
    summarise(total_revenue = sum(Total.Price), .groups = "drop")
  
head(quarterly_institution_revenue)

p2 <- ggplot(quarterly_institution_revenue, aes(x = quarter, y = total_revenue, fill = Institution.Type)) +
  geom_col(position = "stack", width = 0.6) +
  scale_fill_manual(values = c("Internal" = "blue", "External" = "orange")) +
  scale_y_continuous(labels = scales::dollar_format(prefix = "$")) +
  labs(
    title = "Quarterly Revenue Breakdown by Institution Type",
    subtitle = "Stacked var view of internal vs. external revenue",
    x = "Quarter",
    y = "Revenue (USD)",
    fill = "Institution Type"
  ) +
    theme_minimal(base_size = 12) +
    theme(
      plot.title = element_text(face="bold", size = 14),
      legend.position = "bottom"
    )

4.4.3 Line Chart Option

p3 <- ggplot(quarterly_institution_revenue, aes(x = quarter, y = total_revenue, color = Institution.Type, group = Institution.Type)) +
  geom_line(linewidth = 1.2) +

  scale_color_manual(values = c("Internal" = "#2b5c8f", "External" = "#d95f02")) +

4.4.4 Exporint Report-Ready Plots

To export high-resolution figures for reports or internal sharing, we use ggsave().

dir.create("output_plots", showWarnings = FALSE)

ggsave(
  filename = "output_plots/monthly_revenue_trend.pdf",
  plot = p1,
  width = 8,
  height = 5,
  units = "in",
  dpi = 300
)

ggsave(
  filename = "output_plots/quarterly_revenue_institution_stacked.png",
  plot = p2,
  width = 8,
  height = 5,
  units = "in",

)

ggsave(
